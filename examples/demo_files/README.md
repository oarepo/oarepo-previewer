# Test Files

This directory contains test files used for testing the OARepo Previewer functionality.

## File Sources

### Protein Data Bank (PDB) Files
The following files are derived from real structures from the [Protein Data Bank (PDB)](https://www.rcsb.org/):

* **1cbs** - Crystal structure of a protein (multiple formats: `.pdb`, `.cif`, `.bcif`, `.ent`)
  * Source: PDB ID `1CBS`
  * Downloaded from RCSB PDB
* **1h9t.mvsx** - MVSX format file
  * Source: Generated from PDB ID `1H9T`

### Small Molecule Files
Generated by LLM for testing various molecular formats:

* **caffeine.sdf** - Caffeine molecule in SDF format
* **aspirin.sd** - Aspirin molecule in SD format
* **methene.mol** - Methene molecule in MOL format
* **water.pdbqt** - Water molecule in PDBQT format
* **water.mol2** - Water molecule in Mol2 format
* **water.xyz** - Water molecule in XYZ format
* **water.gro** - Water molecule in GROMACS GRO format

### MVS (Mol* Viewer State) Files
Following files for testing viewer state are from the [Molstar repository](https://github.com/molstar/molstar/tree/master/examples/mvs):

* **1h9t.mvsx** - MVSX viewer state for 1h9t structure
* **1cbs.mvsj** - MVSJ viewer state for 1cbs structure
* **1cbs_error.mvsj** - Invalid/corrupted MVSJ file for error handling tests (custom edit of original file)

### Example/Minimal Files
Generated by LLM for testing minimal valid files:

* **example.mmcif** - Minimal mmCIF format file
* **example.mcif** - Minimal CIF format file

# Testing the Previewer

You can use the [nrp-cmd](https://github.com/NRP-CZ/nrp-cmd) CLI tool to quickly generate a test record with your files, bypassing the need to use the UI.

## Setup and Upload

## 1. Setup and Upload

Ensure your local instance is running, then run these commands from your terminal:

```bash
# Install the CLI
uv pip install nrp-cmd

# Connect to your local server (it will prompt you for a token in the browser)
nrp-cmd add repository --no-verify-tls [https://127.0.0.1:5000](https://127.0.0.1:5000) local

# Create an empty draft record (it will save the ID into memory)
nrp-cmd create record '{"title": "Molstar Test Record"}' --repository local --set recid

# Upload the sample molecule files
nrp-cmd upload file @recid path/to/your/1cbs.mvsj --repository local
```

## 2. Fill Required Metadata and Publish

Because different OARepo and Invenio instances use strictly enforced, custom vocabularies (like specific `resource_type` options), it is difficult to bypass the metadata requirements via CLI alone. 

To make the preview links publicly accessible, you must finish publishing the draft in the UI:

1. Check your terminal output from the `create record` step for your **Record ID** (e.g., `6wp9v-4gh15`).
2. Open your draft in the browser:
   `https://127.0.0.1:5000/datasets/uploads/<RECORD_ID>` 
3. The UI will highlight the missing required fields in red (typically Publication Date, Creators, and Resource Type). Select the appropriate options from the dropdowns.
4. Click **Publish** in the top right corner.

## 3. Preview the Files

Now that the record is published, you can view the Molstar previewer via the standard public URLs. Replace `<RECORD_ID>` with your actual ID:

**Molstar Files:**
* `https://127.0.0.1:5000/datasets/<RECORD_ID>/preview/1cbs.mvsj`

*(Note: If you are running standard InvenioRDM instead of the OARepo `datasets` model, replace `datasets` with `records` in the URLs).*
