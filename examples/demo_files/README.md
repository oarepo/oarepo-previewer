# Test Files

This directory contains test files used for testing the OARepo Previewer functionality.

## File Sources

### Protein Data Bank (PDB) Files
The following files are derived from real structures from the [Protein Data Bank (PDB)](https://www.rcsb.org/):

- **1cbs\*** - Crystal structure of a protein (multiple formats: `.pdb`, `.cif`, `.bcif`, `.ent`)
  - Source: PDB ID `1CBS`
  - Downloaded from RCSB PDB
- **1h9t.mvsx** - MVSX format file
  - Source: Generated from PDB ID `1H9T`

### Small Molecule Files
Generated by LLM for testing various molecular formats:

- **caffeine.sdf** - Caffeine molecule in SDF format
- **aspirin.sd** - Aspirin molecule in SD format
- **methene.mol** - Methene molecule in MOL format
- **water.pdbqt** - Water molecule in PDBQT format
- **water.mol2** - Water molecule in Mol2 format
- **water.xyz** - Water molecule in XYZ format
- **water.gro** - Water molecule in GROMACS GRO format

### MVS (Mol* Viewer State) Files
Following files for testing viewer state are from [Molstar repository](https://github.com/molstar/molstar/tree/master/examples/mvs):

- **1h9t.mvsx** - MVSX viewer state for 1h9t structure
- **1cbs.mvsj** - MVSJ viewer state for 1cbs structure
- **1cbs_error.mvsj** - Invalid/corrupted MVSJ file for error handling tests (custom edit of original file)

### Example/Minimal Files
Generated by LLM for testing minimal valid files:

- **example.mmcif** - Minimal mmCIF format file
- **example.mcif** - Minimal CIF format file
